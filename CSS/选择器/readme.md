# 伪类:
用于向选择器添加特殊的状态或条件.他描述的是‘元素在什么状态下’
**1、动态/用户行为伪类**(根据用户操作改变)
:link - 选中还未被访问过的链接
:visited - 选中已被访问过的链接
:hover - 当鼠标指针悬停在元素上时选中该元素
:active - 当元素被激活时(例如,鼠标点击链接但还未松开时)选中该元素
:focus - 当元素获得焦点时(例如,通过Tab键或鼠标点击选中的输入框)选中该元素
**结构性伪类**(根据元素在DOM树中的位置或关系)
:first-child - 选中作为其父元素的第一个子元素的那个元素
:last-child - 选中作为其父元素的最后一个子元素的那个元素
:nth-child(n) - 选中作为其父元素的第n个子元素.n可以是数字、关键字(odd、even)或公式(2n+1)
:nth-of-type(n) - 选中同类型兄弟元素中的第n个
:not(selector) - 选中不匹配括号内选择器的所有元素
:empty - 选中没有任何子元素(包括文本节点)的元素
# 伪元素:
用于在元素特定部分创建虚拟的元素.他描述的是‘元素的哪个部分’

::before - 在选中元素的内部,但在所有实际内容之前创建一个伪元素
::after - 在选中元素的内部,但在所有实际内容之后创建一个伪元素
**注意**:这两个伪元素必须设置content属性才能生效,即使content的值是空字符串‘’

::first-line - 选中块级元素的第一行文本
::first-letter - 选中块级元素的第一个字母

其他
::marker - 选中列表项(<li>)的标记(项目符号或数字)
::seletion - 选中用户用鼠标高亮选中的文本部分
::placeholder - 选中输入框(<input>) 的占位文本
